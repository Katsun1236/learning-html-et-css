# Le Sanctuaire du Web - Learning HTML & CSS

Jeu pedagogique et visuel d'apprentissage du HTML5 et du CSS3 sous forme de Visual Novel immersif aux cotes de Maitre Bodhi.

## Presentation du projet

Dans ce jeu web interactif, vous incarnez un apprenti debarquant devant les ruines du Sanctuaire du Web. Guide par Maitre Bodhi, un vieux moine ermite dont le cache memoire s'efface peu a peu, vous batissez pas a pas un site multipages responsive (`index.html`, `chroniques.html`, `galerie.html`, `contact.html`, `style.css`) a travers 36 etapes rigoureuses.

### Fonctionnalites majeures

- Editeur de code multipages integre avec coloration, autocompletion intelligente et raccourcis clavier
- Rendu en direct instantane dans une fenetre securisee
- Compagnon narratif dynamique (Maitre Bodhi) avec plus de 60 dialogues a embranchements et 12 expressions illustrees
- Systeme d'alignement philosophique invisible a 3 destins : Voie du Phare, Voie du Gardien, Voie du Rebelle
- L'Internet : encyclopedie vivante de 181 fiches decouvertes progressivement au fil du voyage avec chroniques historiques illustrees
- Codes secrets dissimules directement dans le code source
- Espace de travail ergonomique : boite de dialogue et avatar de Bodhi entierement redimensionnables

## Deploiement sur Cloudflare Pages

Le projet est configure pour etre heberge directement sur Cloudflare Pages (aucun build complexe necessaire, distribution purement statique).

Fichiers de configuration inclus :
- `wrangler.toml` : configuration Cloudflare Pages
- `_headers` : regles de mise en cache et de securite HTTP
